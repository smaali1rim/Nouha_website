# Polices

## TAN Meringue (accent / signature)

TAN Meringue est une police commerciale : elle n'est pas incluse dans le dépôt.
Dépose ici les fichiers de ta licence avec **exactement** ces noms :

- `TAN-Meringue.woff2` (recommandé)
- `TAN-Meringue.woff` (optionnel, anciens navigateurs)

Si tu n'as qu'un `.otf` / `.ttf`, convertis-le en `.woff2`
(par ex. avec https://transfonter.org, si ta licence web l'autorise).

Tant que les fichiers sont absents, le site utilise **Fraunces** (Google Fonts,
version « soft ») comme police de remplacement : le rendu reste proche, rond et
généreux.

## Literata & Inter

Chargées depuis Google Fonts dans le `<head>` de chaque page — rien à faire.

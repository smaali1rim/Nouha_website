# Polices

## TAN Meringue (accent / signature)

Police commerciale auto-hébergée : `tan-meringue.woff2`, déclarée en haut de
`assets/css/style.css` (`@font-face`) et préchargée dans le `<head>` de chaque
page (`<link rel="preload" … as="font">`). Si tu remplaces le fichier, garde ce
nom ou mets à jour ces deux endroits.

## Literata & Inter

Chargées depuis Google Fonts dans le `<head>` de chaque page — rien à faire.
